ساخت APK:
1) Android Studio (Giraffe/Hedgehog یا جدیدتر) را باز کنید -> Open -> پوشه CarLauncher
2) صبر کنید Gradle Sync تمام شود (نیاز به اینترنت و JDK 17)
3) منوی Build -> Build Bundle(s)/APK(s) -> Build APK(s)
4) فایل: app/build/outputs/apk/debug/app-debug.apk

یا از ترمینال (اگر gradle نصب است):  gradle assembleDebug
